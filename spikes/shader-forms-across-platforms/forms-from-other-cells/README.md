# Forms made on other cells

The scene's two stages as the first run of the spike on the research CI made them ([run](https://github.com/ludenea/ludenea/actions/runs/43225378062)), one directory per cell that made them and per chain. Each cell draws the scene natively with the forms of the other cells that its device takes: DXIL made on Linux on the Windows cells, Metal text made on Linux and on Windows on the macOS cell, SPIR-V made on Windows on the Linux cells. They are inputs of a measurement, never product assets.
