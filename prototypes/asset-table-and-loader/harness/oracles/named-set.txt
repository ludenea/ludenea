# Family named-set: a named content set under a moved manifest.
# Written by hand from the design text, by a writer who has not read the build.
# The table's order is the order of the asset identifiers: K1, K2, N, X2, X3, Y.
# Where the text left a choice, a comment says which reading the lines take.
# Reading taken throughout: a first arrival emits the event "arrived".
# Reading taken throughout: a tick 0 block states the table the creation gives,
# with an empty record and no event.

scenario named-set/moved-manifest

# The world created under the set. Every want is resolved in the set's manifest,
# whatever has moved the instance's manifest since, and no revision, mount or
# unmount reaches its input record.
world under-set

tick 0
entry K1 unavailable
want contributor:base required
entry K2 unavailable
want contributor:base required
