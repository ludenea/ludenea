# Security policy

## Supported versions

Ludenea has no release yet. Until the first release, only the `main` branch
receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability.

Report it privately through
[GitHub private vulnerability reporting](https://github.com/ludenea/ludenea/security/advisories/new),
or by email at [contact@ludenea.com](mailto:contact@ludenea.com) if you cannot
use GitHub.

Include a description of the problem, the steps to reproduce it and the
affected commit or version. You will receive an acknowledgement within seven
days. Once a fix is available, the vulnerability is disclosed in a security
advisory, with credit to the reporter unless they prefer otherwise.
