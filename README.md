# Ludenea

Ludenea is an original, high-performance, extensible, cross-platform 2D and 3D game engine, written primarily in Rust and built as an independent open-source project.

The project is at its foundations stage: requirements, research and architecture come before any engine code, by design. This repository receives the engine's code and its released documentation as they are ready.
